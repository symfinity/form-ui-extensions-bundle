## Details

### 0.1.x — Metadata foundation

FormView metadata, novalidate strategy, optional uppercase normalization, theme-agnostic architecture, optional UX Blocks bridge, Flex recipe.

### 0.2.x — Form semantics

Extended button metadata, submit intent metadata, standardized form state metadata, reusable metadata contracts.

### 0.3.x — UI metadata

Field grouping metadata, help and hint metadata, icon metadata, layout metadata, component integration improvements.

### 0.4.x — Validation UX

Validation state metadata, error presentation metadata, constraint visualization hooks, client-side integration points.

### 0.5.x — Input normalization

Additional normalization strategies, configurable transformation pipeline, normalization policies, extensibility improvements.

### 0.6.x — Theme interoperability

Expanded integration with Symfony form themes, improved UX Blocks interoperability, consistent metadata mapping, rendering compatibility.

### 0.7.x — Developer experience

Additional CLI tooling, diagnostics, debugging helpers, documentation improvements, migration guidance.

### 0.8.x — Accessibility

Accessibility metadata, ARIA integration helpers, required-field semantics, screen-reader improvements, keyboard interaction metadata.

### 0.9.x — API stabilization

Contract review, deprecation cleanup, extension guidelines, documentation completion, migration handbook.

### 1.0.x — Stable API

Semver-stable extension contracts, stable metadata model, stable normalization API, long-term compatibility policy.
